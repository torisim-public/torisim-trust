# Report a security issue

Email [support@torisim.com](mailto:support@torisim.com) with a description,
affected version or commit, and a minimal reproduction using synthetic data.
For sensitive details, encrypt your report to the public key at
[torisim.com/pgp.txt](https://torisim.com/pgp.txt). Confirm its fingerprint
through a channel you trust before sending.

Do not put credentials, recovery codes, eSIM activation details, payment
records or personal information in public issues. Keep vulnerability reports
private while we investigate. There is no reward or response-time commitment
in this policy.

This repository contains a command-line checker and public file snapshots.
Use its tests or a local fixture for reproductions. It does not authorize
testing other people's accounts, accessing private data, disrupting service,
or probing third-party infrastructure.

The live site's current security contact is published at
[security.txt](https://torisim.com/.well-known/security.txt).
